## Purpose

This rubric provides a structured framework for evaluating the quality of AI-generated responses.

It is designed to support consistent assessment by defining clear criteria and a standardized 0–2 scoring scale. The rubric is used as a general evaluation framework, while individual tasks may use task-specific criteria appropriate to their evaluation objective.

## Usage

The rubric provides a consistent baseline for evaluating response quality across different tasks.

Each criterion is scored independently using the defined 0–2 scale. Task-specific rubrics may adapt the criteria when a particular evaluation objective requires a different focus.

# Response Quality Rubric v1.0

## Purpose

This rubric is used to evaluate AI-generated responses for response quality in realistic user scenarios.

The evaluation focuses on whether a response is relevant, personalized, useful, and clear.

Each criterion is scored from 0 to 2.

---

## 1. Relevance

Measures whether the response directly addresses the user's question or request.

- **2 — Strong:** Directly addresses the user's question and stays focused on the requested task.
- **1 — Partial:** Generally related to the request but misses an important aspect or includes some unnecessary content.
- **0 — Poor:** Does not meaningfully address the user's request.

---

## 2. Personalization

Measures whether the response appropriately uses the specific context provided by the user.

- **2 — Strong:** Clearly incorporates the important details and circumstances provided by the user.
- **1 — Partial:** Uses some of the provided context but remains partly generic.
- **0 — Poor:** Ignores the user's context and provides a generic response.

---

## 3. Usefulness

Measures whether the response provides practical value to the user.

- **2 — Strong:** Provides specific, realistic, and actionable guidance.
- **1 — Partial:** Provides some useful information but lacks sufficient detail or actionable guidance.
- **0 — Poor:** Provides little or no practical value.

---

## 4. Clarity

Measures whether the response is understandable, organized, and easy to follow.

- **2 — Strong:** Clear, concise, well-organized, and easy to understand.
- **1 — Partial:** Understandable but contains some vagueness, repetition, or organizational problems.
- **0 — Poor:** Difficult to understand or poorly organized.

---

## Scoring

Maximum score: **8 points**

| Score | Interpretation |
|---|---|
| 7–8 | Strong response |
| 5–6 | Acceptable response with weaknesses |
| 3–4 | Weak response |
| 0–2 | Poor response |

---

## Evaluation Principle

Evaluators should score based on evidence in the response and the definitions above.

The question is:

> "What evidence in the response justifies this score against the defined criterion?"

Evaluators should avoid scoring based only on personal preference or which response sounds better.
