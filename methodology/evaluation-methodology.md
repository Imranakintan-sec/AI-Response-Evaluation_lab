# AI Response Evaluation Methodology

## Purpose

This document describes the methodology used to evaluate AI-generated responses in this portfolio project.

The goal is to apply structured evaluation criteria consistently, provide clear reasoning for assigned scores, and compare responses based on observable qualities rather than personal preference.

## Evaluation Workflow

Each evaluation follows a consistent sequence:

1. Define the evaluation task and objective.
2. Present the user prompt.
3. Provide two candidate AI responses.
4. Define evaluation criteria appropriate to the task.
5. Evaluate Response A against each criterion.
6. Evaluate Response B against each criterion.
7. Compare the two responses.
8. Select the stronger response and explain why.
9. Record the overall assessment.

## Scoring Approach

Each evaluation criterion is scored on a 0–2 scale:

- **2 — Strong:** The response fully satisfies the criterion.
- **1 — Partial:** The response partially satisfies the criterion or has a notable weakness.
- **0 — Poor:** The response does not satisfy the criterion or contains a significant deficiency.

The total score is calculated by adding the scores for all criteria in the task-specific rubric.

Scores are supported by written reasoning so that the evaluator's judgment can be reviewed and understood.

## Evaluation Principles

The evaluation process follows these principles:

- **Consistency:** Apply the defined criteria consistently across responses.
- **Evidence-based judgment:** Base scores on observable characteristics of the response.
- **Criterion separation:** Evaluate each dimension independently rather than allowing one strength or weakness to determine the entire score.
- **Clear justification:** Explain the reasoning behind each assigned score.
- **Comparative analysis:** Consider the relative strengths and weaknesses of both responses when determining the preferred response.
- **Honest representation:** Distinguish independent portfolio evaluation work from professional or commercial evaluation experience.

## Quality Control

Before completing an evaluation, the following checks are performed:

- Confirm that the user prompt is represented accurately.
- Confirm that the evaluation criteria match the stated objective.
- Check that each criterion is scored using the defined 0–2 scale.
- Verify that each score has a clear written justification.
- Check that the comparative analysis is consistent with the individual evaluations.
- Confirm that the final assessment does not introduce unsupported claims.
- Review the completed evaluation for clarity, consistency, and completeness.

## Scope

This methodology is designed for controlled evaluation of individual AI-generated text responses.

It focuses on response-level qualities such as accuracy, relevance, instruction following, safety, completeness, and appropriate handling of ambiguity.

The methodology is intended for portfolio demonstration and learning purposes rather than production model benchmarking or commercial evaluation.

## Expected Outcome

The methodology is intended to produce evaluations that are:

- **Consistent:** Similar responses are judged using the same defined criteria.
- **Transparent:** Scores are supported by written reasoning.
- **Focused:** Evaluations address the specific objective of each task.
- **Comparable:** Responses can be assessed against the same rubric criteria.
- **Reviewable:** Another evaluator can follow the reasoning behind the assessment.
